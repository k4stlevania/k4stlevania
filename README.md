## 🎮 [Proyecto 1 — Gestion de Videojuegos]

**API REST para administrar videojuegos, desarrollada con Spring Boot.**

Una aplicación backend que permite gestionar videojuegos mediante operaciones CRUD y una base de datos relacional.

### Características

* Crear, editar y eliminar videojuegos
* Buscar videojuegos
* Gestión de categorías
* Persistencia mediante JPA/Hibernate
* API REST
* Validación de datos

### Tecnologías

`Java` `Spring Boot` `Spring Data JPA` `MySQL` `REST API`
